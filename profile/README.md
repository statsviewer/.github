# StatsViewer

Privacy-conscious analytics for websites and apps.

StatsViewer gives developers a focused view of visitors, sessions, screens, custom events, and goals—without advertising profiles or unnecessary personal data.

## Build with StatsViewer

- Add the lightweight browser script to a website
- Track React Native and Expo apps with [`@statsviewer/react-native`](https://www.npmjs.com/package/@statsviewer/react-native)
- Add analytics to Unity projects with the [StatsViewer Unity package](https://github.com/statsviewer/unity-plugin)
- Connect native Swift and Kotlin apps
- Send trusted server-side events through the versioned HTTP API

## Get started

- [Visit StatsViewer](https://statsviewer.com)
- [Read the documentation](https://statsviewer.com/docs)
- [Install the React Native package from npm](https://www.npmjs.com/package/@statsviewer/react-native)
- [View service status](https://statsviewer.com/status)

```bash
npm install @statsviewer/react-native @react-native-async-storage/async-storage
```

StatsViewer is built for useful product analytics with a smaller data footprint: cookie-free website tracking, Do Not Track respected by default, and application SDKs that avoid advertising and hardware identifiers.
